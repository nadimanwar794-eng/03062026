---
name: Bottom navigation indicator
description: Visual rule for the student app's active bottom-navigation state.
---

The active bottom-navigation state should be a borderless pop-out bead with a curved nav-edge notch; do not use a circular ring around the bead or broad colored haze.

**Why:** The reference design uses a smooth U-shaped curve in the nav edge around the raised button. A separate circular ring reads as an unwanted outline, and a broad colored glow makes the footer feel less polished.

**How to apply:** Keep the active button borderless and raised more than halfway above the bar. Build the notch as a narrow curved edge and keep any color spill local and subtle below the bead.
